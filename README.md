# File Upload for MW WP Form

MW WP Form の `[mwform_file]` と `[mwform_image]` を、このプラグインの非同期アップロードに置き換える WordPress プラグインです。

MW WP Form 5.2 では、この2つのショートコードが削除されます。このプラグインを有効にすれば、フォームの本文を書き換えずに、5.1.x でも 5.2 以降でも同じようにファイルを受け付けられます。

> **注意**: このプラグインは MW WP Form の公式品ではありません。MW WP Form の開発元とは関係がありません。

## 動作環境

- WordPress 6.0 以上
- PHP 8.0 以上
- MW WP Form 5.1.8 で動作を確認しています。5.2 については、ファイル関連の機能を取り除いた状態を再現してテストしています。5.2 がリリースされたら、実物で確認し直します。
- Apache と Nginx のどちらでも動きます。Nginx の場合は、[Nginx](#nginx) の設定をしてください。
- フォームを使う人のブラウザで JavaScript が有効になっている必要があります。無効の場合は、ファイル項目に案内が表示されます。

## インストール

1. [Releases](https://github.com/stagehand-wp-plugins/mwwpf-file-upload/releases) の最新版から `mwwpf-file-upload.zip` をダウンロードします。
   **「Source code (zip)」は使わないでください。** 動作に必要なファイルが入っていません。
2. WordPress の管理画面で「プラグイン → 新規追加 → プラグインのアップロード」を開き、zip をアップロードします。
3. プラグインを有効にします。

有効にすると、既存のフォームにある `[mwform_file]` と `[mwform_image]` が、すぐにこのプラグインのものに置き換わります。フォームの本文や設定を変える必要はありません。

## 何が変わるか

- ファイルを選ぶと、その場でサーバーに送られます。確認画面や、入力エラーで画面が戻ったときも、選んだファイルは残ります。
- 管理画面のバリデーション設定（ファイルの種類、サイズの上限・下限、必須）は、これまでどおり効きます。
- 管理者宛てのメールには、元のファイル名で添付されます。自動返信メールには添付されません。これは MW WP Form と同じ動きです。
- MW WP Form の「問い合わせデータをデータベースに保存」を使っている場合、問い合わせデータにはファイル名だけが残ります。ファイルはメディアライブラリに登録されません。
- 管理画面に出ていた MW WP Form の削除予告（ファイル項目が 5.2 で削除されるという通知）は表示されなくなります。このプラグインがあれば、5.2 以降もファイル項目を使えるためです。

## 送信されたファイルの確認

送信されたファイルは、「MW WP Form → 添付ファイル」で確認できます。

- この画面を使えるのは管理者だけです。ファイルの一覧表示、ダウンロード、画像のプレビュー、削除ができます。
- ファイルは、送信から一定の期間（既定は30日）保管され、その後自動で削除されます。期間はこの画面で変えられます。0日にすると自動では削除されません。
- 保管されたファイルは外部に公開されません。

## 保管場所

アップロードされたファイルは、既定では `wp-content/uploads/mwwpf/` に保管されます。

- 送信前のファイルは `tmp/` に、送信されたファイルは `files/` に入ります。
- Apache の場合は、プラグインが置く `.htaccess` によって、外部から直接アクセスできないようになっています。
- 「添付ファイル」画面の「保管場所」欄に、今の保管場所と、外部からアクセスできるかどうかの確認結果が表示されます。

### 保管場所を公開ディレクトリの外に移す（推奨）

`wp-config.php` の「編集が必要なのはここまでです」より上に、次のように書きます。

```php
define( 'MWWPF_STORAGE_DIR', '/home/example/mwwpf-storage/example.com' );
```

- ドキュメントルートより外にある、PHP が書き込めるフォルダを指定してください。フォルダがなければ、プラグインが作ります。
- 保管場所が公開ディレクトリの中にある間は、「添付ファイル」画面に、このサーバーで使えるパスの例が表示されます。
- 相対パスを指定した場合や、WordPress 本体・`wp-content`・プラグイン・テーマ・`uploads` のフォルダそのものかその親を指定した場合は、設定が無視されます。その場合は既定の場所が使われ、管理画面にエラーが表示されます。
- ファイルは自動では移動しません。すでに保管されているファイルを引き継ぐ場合は、元の場所にある `tmp/` と `files/` を、新しい場所に手で移してください。移さなかったファイルは「添付ファイル」画面に表示されなくなります。

### Nginx

Nginx では `.htaccess` が効きません。そのため、既定の保管場所のままだと、ファイルが外部から読める可能性があります。その場合は、管理画面に警告が表示されます。

次のどちらかで対応してください。

1. **推奨**：保管場所を公開ディレクトリの外に移します（[前の節](#保管場所を公開ディレクトリの外に移す推奨)を参照）。
2. Nginx の設定で、保管場所へのアクセスを拒否します。KUSANAGI の場合は、サイトの `server` ブロックに次を追加します。

   ```nginx
   location ^~ /wp-content/uploads/mwwpf/ { deny all; return 404; }
   ```

   設定を反映したら、「添付ファイル」画面の「再確認」を押してください。外部からアクセスできないことが確認されると、警告は消えます。
   確認が済んでいても警告が残る場合は、`wp-config.php` に `define( 'MWWPF_STORAGE_PROTECTED', true );` を書くと、警告を消せます。

### Basic 認証をかけているサイト

サイト全体に Basic 認証がかかっていると、外部からのアクセスの確認では「アクセスできない」と判定されます。認証によって拒否されるためです。

公開前にステージングなどで認証をかけていた場合は、認証を外した後で、「添付ファイル」画面の「再確認」を押してください。

## 更新

新しい版が出ると、ほかのプラグインと同じように、管理画面に更新の通知が表示されます。「今すぐ更新」で更新できます。

自動で更新するかどうかは、サイトごとに選べます。「プラグイン」画面で、このプラグインの「自動更新を有効化」を切り替えてください。

## 無効化とアンインストール

- 無効にしても、保管されたファイルは消えません。
- **プラグインを削除すると、保管されたファイルもすべて削除されます。** 必要なファイルは、削除する前に「添付ファイル」画面からダウンロードしてください。
- MW WP Form の問い合わせデータは削除しません。

## 開発者向けの設定

| 名前 | 種類 | 既定 | 内容 |
|---|---|---|---|
| `MWWPF_STORAGE_DIR` | 定数 | `uploads/mwwpf` | 保管場所 |
| `MWWPF_STORAGE_PROTECTED` | 定数 | なし | true にすると、保管場所の警告を出しません |
| `MWWPF_UPDATE_PRERELEASES` | 定数 | なし | true にすると、プレリリースも更新として通知します（ステージング用） |
| `mwwpf_default_max_bytes` | フィルター | 10MB | サイズの上限を設定していない項目の上限 |
| `mwwpf_default_exts` | フィルター | ファイル: `pdf, jpg, jpeg, png, gif, webp, heic, doc, docx, xls, xlsx, ppt, pptx, txt, csv, zip`／画像: `jpg, jpeg, png, gif, webp` | ファイルの種類を設定していない項目で受け付ける拡張子 |
| `mwwpf_tmp_ttl` | フィルター | 86400 秒 | 送信前のファイルを残しておく時間 |
| `mwwpf_rate_limit` | フィルター | 600秒に30回 | アップロードの回数制限 |
| `mwwpf_tmp_quota_bytes` | フィルター | 500MB | 送信前のファイルの合計の上限 |
| `mwwpf_admin_capability` | フィルター | `manage_options` | 「添付ファイル」画面を使える権限 |
| `mwwpf_server_ignores_htaccess` | フィルター | Nginx なら true | 確認結果がないときに、保管場所の警告を出すかどうかの判定 |
| `mwwpf_hide_deprecation_notice` | フィルター | true | false にすると、MW WP Form の削除予告を表示します |

実行ファイルなどの危険な拡張子（`php`、`js`、`html`、`svg` など）は、どの設定でも受け付けません。
